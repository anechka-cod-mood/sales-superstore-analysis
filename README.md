# Sales Superstore Analysis

## Project Overview

Exploratory Data Analysis (EDA) of the Sample Superstore dataset.

The project investigates:

- Sales performance
- Profitability
- Discount strategy
- Customer segments
- Product categories
- Regional performance

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Results

The analysis includes:

- Data preprocessing
- Business recommendations
- Statistical summaries
- Data visualization
